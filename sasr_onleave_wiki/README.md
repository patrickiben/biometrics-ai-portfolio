# Continuity and handoff tools

Open the [toolkit control panel](../toolkit_launcher/index.html) and choose Continuity or the coverage playbook; no R is required. The [setup guide](../TOOLKIT_SETUP.html) explains private project copies and exporting work.

[Continuity workspace](Continuity_Toolkit.html) · [Playbook](On_Leave_Coverage_Playbook.html) · [CSV template](continuity_jobs_template.csv). Enter or import recurring jobs in the workspace and export JSON/CSV or a printable handoff packet. Browser localStorage is not included in a project ZIP.
