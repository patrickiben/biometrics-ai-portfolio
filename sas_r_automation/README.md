# SAS/R monitoring automation templates

Use the [point-and-click toolkit setup](https://patrickiben.github.io/biometrics-ai-portfolio/TOOLKIT_SETUP.html) to create a private project, prepare monitoring settings and open the templates in your SAS or R editor. The configuration action prepares files; it does not run monitoring or send email.

[Automation guide](SAS_R_Trial_Monitoring_Automation.html) · [Macro library setup](macro_library/README.md). Feed mapping, reviewed thresholds, runtime, scheduler, service account, recipients and SMTP remain deployment-specific. The SAS code has not been executed.
