# SAS/R monitoring automation templates

Use the [point-and-click toolkit setup](https://patrickiben.github.io/biometrics-ai-portfolio/TOOLKIT_SETUP.html) to select checks, upload study feeds, map columns and review thresholds. Preview and generate a private monitoring package with a configured SAS driver, reusable profile and setup report. Generation does not run SAS, connect feeds, schedule checks or send email.

[Automation guide](SAS_R_Trial_Monitoring_Automation.html) · [Macro library setup](macro_library/README.md). Feed mapping, reviewed thresholds, runtime, scheduler, service account, recipients and SMTP remain deployment-specific. The SAS code has not been executed.
