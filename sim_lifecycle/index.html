PK and clinical pharmacology

PK, NCA and bioequivalence sandbox

Runs in base RSynthetic data

One synthetic early-phase clinical pharmacology study, taken through the analysis steps: synthetic ADaM, PK and NCA, then summary computations. Base R, seeded, runs offline.

What it does

  • A generator (simulate_adam.R) writes eight ADaM-shaped domains: ADSL ADEX ADPC ADPP ADAE ADVS ADLB ADEG.
  • PK comes from a one-compartment oral model. NCA uses the linear trapezoidal rule for AUC to the last sample, a terminal slope fitted to the last three points, and AUC to infinity, CL/F and Vz/F from that slope.
  • The design is a 2x2 bioequivalence crossover with per-period safety domains (N = 40, seed 2026).
  • The driver (run_lifecycle.R) prints demographics, geometric means and geometric CV% on the log scale, the bioequivalence analysis (a fixed-effects model on log values with participant, period and treatment; geometric mean ratio and 90% confidence interval), an adverse-event overview counted by participant, and vitals, lab and ECG summaries.

What it is not

  • Not a validated NCA. The NCA here is a short base-R implementation on nominal sampling times with a fixed three-point terminal fit. In a study, NCA comes from a validated system such as Phoenix WinNonlin or a qualified PKNCA setup, on actual sampling times.
  • Not checked by Pinnacle 21 or CDISC CORE. The domains pass the repository's own structural checks (domains present, keys intact, well-formed parameter codes, sequence matches treatment).
  • The drafting step is a stub. With no language model installed, tlf_interpret prints a stub draft; only its number check runs.
  • The calibration targets (for example Cmax CV 36%) were fitted from 42 public early-phase registrations on ClinicalTrials.gov. That harvest is not included, so the targets cannot be re-derived from this repository; the resulting priors are written into priors.R.
  • The SAS and R TLF libraries are written against these domain shapes but have not yet been run on these files.

Synthetic data only

The design structure (design mix, enrollment size, healthy-volunteer rate, randomization and masking, site geography) follows public Phase 1 registration patterns on ClinicalTrials.gov. All participant-level data is simulated from generic priors for an oral small molecule and healthy-volunteer adverse-event rates. It is not fitted to any sponsor, and no real participant data is used or reproduced.

Run it

Rscript sim_lifecycle/run_lifecycle.R

Run from the repository root. Base R only (tested with R 4.6.0). The drafting step loads tlf_interpret/ and falls back to its stub when no model is installed.
