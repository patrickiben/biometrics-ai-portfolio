Open the toolkit on your computer

The local launcher adds private projects, setup checks, file selection and run controls. Keep the downloaded toolkit folder together.

  1. Download and unzip the toolkit

    Save the complete folder anywhere convenient on your computer.

  2. Double-click Start Toolkit

    Open Start Toolkit.command on macOS or Start Toolkit.cmd on Windows, in the toolkit’s top-level folder.

  3. Create your own project

    The launcher opens this page with local controls. Create a private copy of the synthetic examples, then open the tool you need.
