# cubature for the bundled webR runtime

The toolkit supplies a rebuilt **cubature 2.1.4-1** package because the published upstream Wasm artifact imports `emscripten_longjmp`, while the bundled webR 0.6.0 runtime uses the Wasm exception/long-jump ABI (`__wasm_longjmp`). Loading the incompatible artifact prevents PowerTOST and subsequent dynamic libraries from loading.

This artifact changes **only `src/Makevars.webr`**, the package's build recipe. It adds the runtime's `-fwasm-exceptions -sSUPPORT_LONGJMP=wasm` flags to the nested C-library builds and renames a local variable that collides with rwasm's compiler configuration. All 144 other upstream files, including every scientific R/C/C++ source file, remain byte-identical. No function, integrator, statistical method, parameter or tolerance is substituted.

`lock.json` records the source commit/archive hash, immutable official toolchain image, R/Rcpp/Emscripten versions, package hash and compiled-library hash. `cubature_2.1.4-1_source.tar.gz` is the complete corresponding upstream source; `Makevars.webr.patch` and `rebuild.py` supply the complete build modification and recipe. The `.tgz` includes the webR filesystem metadata generated by rwasm.

The package remains under its upstream **GPL-3** license. The bundled Cuba library is LGPL-3; the bundled cubature C library is GPL-2-or-later. Their copyright and license notices remain in the source archive and the adjacent text files. These third-party licenses are separate from the toolkit's MIT license.

Developer verification and rebuilding:

```sh
python3 browser_modules/compat/cubature/rebuild.py
python3 browser_modules/compat/cubature/rebuild.py --rebuild --work /path/to/external-build-folder
```

The default verification checks the pinned binary, source archive and patch, reapplies the compiler change and proves that no other upstream file changed. Rebuilding needs Podman or Docker and downloads the pinned official image plus Rcpp 1.1.2 if absent. Build timestamps may change archive bytes; a new binary must receive fresh browser numerical QC before updating the release checksum. These are maintainer steps; toolkit users do not install a compiler or run commands.

The Pages hook is `rebuild.install_into(site)`, called after Shiny export and before generating the package checksum index. The release QC report records actual browser execution and comparisons against native R.

Primary sources: [pinned upstream package source](https://github.com/cran/cubature/tree/37d942bc38c96384380252412e9ca60f22ac186d), [webR package build documentation](https://docs.r-wasm.org/webr/latest/building.html), [official webR 0.6.0 toolchain](https://github.com/r-wasm/webr/tree/v0.6.0).
