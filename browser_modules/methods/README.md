# Browser methods workspace

Choose a method, review its assumptions, confirm and run. The workspace uses the toolkit theme and runs R in the browser through the pinned Shinylive/webR build. It starts without a selected method. Module links may preselect a form but never execute it.

- **PK/NCA/BE sandbox:** configure the synthetic crossover participant count, seed, true ratio and within-participant CV. The original eight domains, statistical summaries, deterministic number-grounded text and N=400 calibration diagnostic all execute. The default reproduces the nine committed CSVs. The complete workflow can take several minutes depending on your device.
- **Residual carryover:** choose participant count, seed, half-life, true ratios, washouts, mono/biexponential disposition and sampling/assay configurations. All six canonical analysis arms and three endpoints are retained with evaluability, paired contrasts and Monte Carlo SEs. The separately exported ADPC/ADPP demonstration remains the original fixed 48-hour example.
- **C-QTc hysteresis:** choose any of the 32 canonical scenarios and the Monte Carlo, sign-vector and bootstrap precision. Scenario seeds retain their original indices when selecting subsets. Optional noise-free controls and fixed worked checks use the canonical functions. A full published grid is available; it can take substantially longer than a small exploratory run.
- **Worked bioequivalence study:** execute all six fixed SIMBE01 stages, including metadata checks, XPT and Dataset-JSON, RTF tables, NCA/BE, the 40-check same-author QC ledger and number-checked CSR text. Browser HTML replaces the external Quarto presentation step. The authored study/SAP/CSR assumptions remain fixed; this is an educational reproduction, not a configurable client-study generator.

Changes invalidate prior results and exports. Reloading stops a long run and clears the session. Save the complete review ZIP before leaving; no account, local R, model service or installation is required. Browser memory, package availability and computing speed remain practical limits.

The ZIP contains reviewed source, configuration, complete CSV/RDS outputs, figures, warnings, execution log, actual software versions and an MD5 file inventory. Tables are paginated in HTML; the live preview shows at most 1,000 rows, while downloads retain every row. Downloads use a browser ZIP implementation with a 50 MiB encoded transfer cap; individual-file downloads remain available for larger bundles. Only synthetic inputs are supported by these method examples.

These modules do not execute SAS and do not claim equivalent SAS analyses. The worked study includes SAS XPORT transport files; the separate paired TLF library provides SAS reference programs. Execution and same-author checks are not scientific approval, independent double programming or regulatory qualification.

`browser_modules/tests/methods.R` checks canonical numerical parity, seeded reproducibility, subset-invariant scenario seeds, exact-binomial interval boundaries, invalid inputs, capacity limits, state restoration, full study artifacts, portable inventories and failed-run cleanup. The Pages smoke specification additionally executes the sandbox in actual browser R. Full browser QC also covers study, all carryover branches, all 32 C-QTc scenarios, download integrity, input invalidation, reset, theme and phone layout.
