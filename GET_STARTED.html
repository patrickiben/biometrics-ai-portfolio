One control panel for the complete toolkit

Follow the point-and-click setup guide: download and extract the complete ZIP, double-click Start Toolkit, create a private project from the examples, then choose a module card. Check dependencies, install supported R packages, start local apps, run the reproducible examples, upload documented inputs and export your project from the browser. The source examples remain available as a baseline.

All five Shiny apps are included: TRIALMON, lifecycle, UAT, risk and hours. Move from the example to your study

  1. Keep a complete checkout and preserve the example. Run its demo and checks first so you have a known baseline.
  2. Map inputs explicitly. Keep stable IDs, expected column names, date formats and units. Replace demo owners, thresholds, weights and assumptions with reviewed values.
  3. Exercise boundary cases. Try missing and malformed inputs, empty datasets and known exceptions. Compare key totals and decisions with a small independently checked example.
  4. Choose persistence and access. Export browser work; back up local files. For the shared tracker, use the guided setup and choose a host when the team is ready. SMTP is needed only for live email; preview files work locally.
  5. Document review for the intended use. Retain the input version, software version, results and reviewer decision under your organization's process.
