# Operational risk signals

Create a private project with the [point-and-click toolkit setup](../TOOLKIT_SETUP.html), then use the Risk card to check packages, upload `shiny/data/signals.csv` and start the local app. This app needs local R; it has no published Shinylive build.

[Input contract and persistence](shiny/README.md) · [Guide](quarto/risk-guide.html). What-if changes are session-only and do not update the input file. The starter signals are synthetic; weights and thresholds need review for a new study.
