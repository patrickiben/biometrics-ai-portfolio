Before you start

  • Synthetic data only. Every study, participant, site and number here is invented for this portfolio.
  • R runs in your browser. Shinylive and webR run the same R code as local R; nothing you enter leaves your computer.
  • First visit: about {{download_mb}} MB to download, usually {{first_s}} seconds on a fast connection and longer on a slow one. Later visits take {{revisit_s}} seconds, because R starts fresh each time.
  • Local R: shiny::runApp("{{source}}") from the repository.
