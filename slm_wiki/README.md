# LOCALMIND helper templates

Use the [point-and-click toolkit setup](https://patrickiben.github.io/biometrics-ai-portfolio/TOOLKIT_SETUP.html) to map a findings CSV, choose controlled labels and local-model settings, and generate a private language-review package. Findings start unapproved; generated settings and drivers require no study-path or variable-name edits. Generation does not install or contact a model.

[Library guide and input contract](macro_library/README.md). Configuration does not download model weights, start a service or make the templates production-ready. SAS/R owns numerical work; consequential language outputs require human review.
