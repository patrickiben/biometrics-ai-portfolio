Summary

Bioequivalence of the test tablet (T) to the reference tablet (R) was shown for both primary parameters in 38 participants (bioequivalence set). The ratio of geometric means T/R was 101.07% for Cmax (90% CI 98.89% to 103.30%) and 103.99% for AUC(0-t) (90% CI 98.52% to 109.75%), both within 80.00% to 125.00% (ICH M13A). The supportive AUC(0-inf) ratio was 104.62% (98.63% to 110.97%) in the 37 participants whose AUC(0-inf) met the SAP parameter rules in both periods.

The within-participant CV was 5.6% for Cmax and 14.0% for AUC(0-t), below the 25% assumed in the sample size, so both intervals are narrower than planned. In this simulation Cmax varies little within a participant because the simulator’s occasion-to-occasion variability acts on clearance.

NCA

PKNCA 0.12.1 on actual sampling times (pre-dose samples at time 0), AUC by linear-up/log-down (linear when a concentration is 0), values below the LLOQ set to 0 wherever they fall and left out of the lambda z fit (conc.blq = list(first = "keep", middle = "keep", last = "keep")), lambda z from at least 3 points after tmax chosen by adjusted R-squared. The SAP parameter rules are applied with PKNCA exclude(): AUC(0-inf) is not summarized or analyzed when more than 20% is extrapolated, and lambda z-based parameters when the adjusted R-squared is below 0.90; the values stay in ADPP with NCAEXRSN set.

What this report is and is not

  • It is executed output from one script (study/run_all.R) on synthetic data, with package versions pinned in study/renv.lock.
  • The results were re-derived by a second method by the same author (NonCompart for NCA, two other fitting routes for the model); see the QC ledger. That is not independent double programming by a second person.
  • Not a validated system, not a submission package: no define.xml, no ADRG, no Pinnacle 21 or CDISC CORE run.
